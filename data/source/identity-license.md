# Data license and provenance

项目代码使用 MIT License。仓库维护者原创整理、且有权许可的事实型数据以
[CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/) 方式提供。

来自 Liquipedia 的记录按其要求归属 Liquipedia contributors，并遵循
[CC BY-SA 3.0](https://creativecommons.org/licenses/by-sa/3.0/)。每条生成记录必须
保留页面 URL、MediaWiki revision ID 和 revision timestamp，不能去掉来源归属。

每条选手记录都必须列出来源。外部来源自己的内容、商标、头像和数据库权益仍受其
各自条款约束；本项目不会因为记录一个来源 URL，就声称重新许可该网站的内容。

从比赛 Demo 提取的 SteamID、当场昵称、当场队伍等原始观测应保留比赛、地图、时间
和 Demo 哈希。只有人工或规则审核通过的身份关系才能进入正式 registry；有冲突的
观测留在待审核区，不能覆盖已确认映射。
