# CS2 对局模拟：玩机器解说研究与原创可用语料库

> **版本：2026-10-26。** 文档含 **180 条原创解说模拟台词**、**8 段连续回合解说样本**、**23 条独立基础来源（24 项基础索引含 1 个同源章节重复项）**、**29 个少见事件摘要卡片**、少量可核验的短引句，以及事件选择策略。
> **特别注意：180 条台词全部是为游戏创作的原创示例，不是玩机器本人说过的原话。** 本次检索无法可靠完成数百段视频的逐句收听、校对与授权核实，因此没有虚构“200句玩机器原话”。完整赛事视频多为二创转载，视频标题可能采用概括或戏谑命名，不等于逐字实录。

## 一、最值得模仿的是他的“比赛阅读过程”

他在 [2016年采访](https://dj.sina.com.cn/article/fxxneua4116120.shtml) 中表达过希望融合战术判断、娱乐表达和高潮解读；在 [2026年9月采访](https://csgo.5eplay.com/article/260913vxjp6z) 中又解释了大量观赛、POV复盘与长期战术积累如何帮助提前判断。这是模拟器最应实现的部分，而不是简单复读热梗。

**节奏变化。** 同一回合先讲战术，再追随画面，爆点转成短句，残局放大停顿，打完回归复盘。 正常回合不要连续三个感叹号；真正高能时才提高重复、呼名和追问。
**表达机制。** 先判断可能发生什么，再描述发生了什么，最后解释为什么会发生。 经常用“先看位置”“注意小地图”“不是枪法问题，是补枪时间差”之类结构；这些是分析后的原创归纳，不是逐字口头禅。
**角色偏好。** 讲清选手站位、战队风格、回合经济与经典历史会提高代入感。 明星选手可以获得较多镜头，但应让数据与实际比赛状态决定重点，避免每局都围绕某一个选手展开。
**情绪阈值。** 前期淡定，中期猜测，首次击杀加速，第二个击杀明显升调，1vX反转或赛点再进入极高情绪。 有失误时先指出合理解法，再追问为什么没这么做，不要对所有空枪无脑怒骂。
**禁忌。** 不要把观众弹幕与二创命名当成玩机器本人原话；不要把本项目原创台词称作真实转录。 不要生造比分、道具、位置、选手历史、回防路径、击杀人数和局势；不确定时降低确信度。

### 建议的生成权重与状态机（设计建议，非主播统计）

- 对局常态：**55% 战术解读 + 30% 事件推进 + 10% 情绪/幽默 + 5% 历史/人物叙事**。高潮阶段动态提升情绪反应占比。
- 回合状态：`BUY → DEFAULT → CONTACT → EXECUTE → POSTPLANT/RETAKE → CLUTCH → RESOLUTION`。每一步只选符合阶段与事实的语句。
- 情绪强度：`0.15` 常规开局；`0.3` 控图；`0.55` 首次击杀；`0.75` 连杀；`0.9` 1vX胜局逆转；`1.0` 赛点极限逆转。不要固定每句喊叫。
- 对于战术意图，区别“**事实**”与“**推测**”：`已经在A大出现三人`是事实；`可能打A`是推测。推测必须使用“像是”“我感觉”“很可能”等标记。
- 去重机制：近6个小事件不重复同模板；同个梗至少冷却4–6回合；每局允许0–2次极高能爆发；失误必须指出具体错误。

## 二、真实材料的极短引句与辨伪

这一节仅给出少量有出处的**短引句／关键词**以便定向复核。分清 `本人访谈`、`二手引述`、`视频标题`、`网友转写`。**视频不能仅凭标题认定为精确逐字稿**。

1. **“警中烟一散”与“露出獠牙”**（引述）。2018年的TYLOO vs Renegades，somebody混烟等待烟散；赛事复盘引用了玩机器解说。 [查看来源](https://csgo.gamersky.com/201806/1057116_5.shtml)。
2. **“真大接” / “超级大爆” / “闪是好闪”**（赛事官方总结）。完美世界上海Major解说阵容介绍明确列举其代表梗，适合当极低频装饰语。 [查看来源](https://www.csgo.com.cn/article/details/20241101/225768.html)。
3. **“熟能生巧”**（本人访谈）。解释战术提前预判依赖长期观赛、POV、对地图结构的理解。 [查看来源](https://csgo.5eplay.com/article/260913vxjp6z)。
4. **“别让这枪成为遗憾”**（视频标题中的短语）。关键大狙空枪引发心痛和历史回顾，需回看视频校对。 [查看来源](https://www.bilibili.com/video/BV1QPJVzdEv3/)。
5. **“全都是尿啊”**（社区转写）。常见于2025年A队残局的社区转写；不同复述存在出入。 [查看来源](https://m.hupu.com/bbs/632841448.html)。
6. **“这是人类的反应啊”**（视频标题中的短语）。用于表达对守狙没有反应的惊讶及不满；标题概括需校对。 [查看来源](https://www.bilibili.com/video/BV1QPJVzdEv3/)。
7. **“黑暗中的鼠光”**（视频标题中的短语）。对弱势选手突然救世的文学化夸张，属于名场面标题表达。 [查看来源](https://www.bilibili.com/video/BV1QPJVzdEv3/)。
8. **“包的”**（视频标题中的短语）。被切片频道归纳为一段时间的口头禅，但不能推定所有场景都适用。 [查看来源](https://www.bilibili.com/video/BV1EikUB3Eh7/)。
9. **“这都能赢？”**（视频标题中的短语）。局势出乎意料时的常见反问，但非个人专有表达。 [查看来源](https://www.bilibili.com/video/BV1RNgd6kExK/)。
10. **“先瞄准再空枪”**（节目主题）。剪辑者的概括性命名，不应当作主播真实原话。 [查看来源](https://www.bilibili.com/video/BV1EikUB3Eh7/)。

## 三、180 条原创模拟台词

使用方法：每条 `{变量}` 必须用游戏引擎中已知事实填充；选择条目时按比赛事件和情绪决定，不应仅按随机数抽取。

### 01｜开场、赛前和回合框架（round_intro，calm）

- **01-01** 好，双方来到{地图}，这一张图先看{攻方}怎么处理进攻方的第一轮控图。
- **01-02** 现在比分是{比分}，{领先方}领先归领先，但这个半场的经济还没有完全拉开。
- **01-03** 先说一下站位，{守方}这边采用的是{防守结构}，把更多资源压到了{防守重点}。
- **01-04** {攻方}这套阵容的个人能力没问题，今天更关键的是中期决策能不能跟得上。
- **01-05** 这一回合非常关键，输掉的话{潜在劣势方}接下来可能就没有正常配枪的空间了。
- **01-06** 从之前几分能看出来，{攻方}对于{争夺区域}的控制欲望非常强，这分大概还会接着试。
- **01-07** 看一个有意思的细节，{选手甲}这次开局拿的位置跟上一回合完全不一样。
- **01-08** {守方}显然做过准备，{点位}上不止一个人，后面还有一个随时能补枪的位置。
- **01-09** 好，先不要急着下结论，{攻方}前面两回合都做过假动作，关键是后面真往哪边走。
- **01-10** 现在场面还算安静，但从道具分布看，双方其实已经在争这一片地图控制了。
- **01-11** 你别看比分差得不大，{落后方}拿到的这几分全是硬仗，经济压力一直没有消失。
- **01-12** {选手甲}今天的手感是个变量，之前几回合他在{交火区域}都已经先拿到了优势。
- **01-13** 这是一个典型的需要指挥站出来的回合，五个人会打枪不代表五个人能打到一起。
- **01-14** 两队都没有急着交底牌，现在拼的是谁先拿到信息、又能不能守住信息差。
- **01-15** 这一分如果{攻方}能够拿下，整个半场的节奏就有可能发生变化，我们往下看。

### 各类原始资料应该怎样使用

1. **完整录播 / 分图录像**：优先标注每回合控制信息、战术猜测、确认击杀、经济预测和局后复盘；少用剪辑标题作为词库。可以从R10、R11、R13–R18、R21随机取15–20个普通回合，比观看100条高能切片更适合校准“日常语速”。
2. **异常场面 / 离奇失误**：R03、R05、R09、R12、R20、R23、R27–R28。使用“期待→反转→验证→复盘”框架；必须允许预测失败后立即修正，不要为戏剧化把比赛状态说错。
3. **比赛外剧情**：R08、R19、R25、R26、R29。赛点、冠军和草根比赛的权重并不相同，不能所有赛事一律用决赛模式。
4. **现成语音短素材**：R02可以研究停顿、上扬、叹气、加速，但未经授权不要直接抽取、分发或克隆原始人声。
5. **斗鱼鱼吧合集入口**：R27与R28指向同一个作者动态集合页，页面可能不断变动；它们算不同研究事件，**不算两个独立网址**。

### 二次审校：八个原创连续解说样本的比分校验

已针对样本M01、M02、M04、M05、M06、M08重新校正人数推进。例如5v5先有一人被击杀，应进入5v4而不是随意跳成4v4；必要时增加一换一以解释人数变化。M08的落后方赢得对手赛点回合只能**续命**，不能直接宣称整个地图结束。**真实引擎仍需实时计算 alive，不应从任何自然语言范例反推出事实。**
