# 教练、暂停与团队状态

教练姓名和行为型为游戏画像，不代表真实俱乐部教练。

| 类型 | 状态触发 | 主要选择 |
| --- | --- | --- |
| 止损 | 最近三回合至少丢两分 | 稳定状态 |
| 趁势 | 最近三回合至少拿两分 | 位置计划 |
| 后手 | 对方近期暂停 | 位置计划 |
| 经济 | 平均资金处于 $3,600–6,500 的关键长枪区间 | 统一预算 |
| 大场面 | 任一方至少 11 分或已进入加时 | 稳定状态 |
| 机会 | 六回合后，有近期得失分趋势，小概率调用 | 位置计划 |

符合条件仍经过 seeded 决策抽样，不按固定回合机械暂停。每图最多四次，两个完整回合冷却；当前规则包不额外补发加时暂停。该限制是游戏统一配置，并非声称所有现实赛事都采用同一规则。

每次手动暂停显示三项基于实时比分、近期丢分、包点与己方平均资金的建议：

1. **位置计划**：CT 下一回合重防所选点，另一侧人数减少；T 下一回合双路夹击所选点，放弃其他点的牵制。不会增加枪械伤害。
2. **稳住节奏**：未来两回合缩小状态方差。减少失误，也削弱过度爆发。
3. **统一经济**：下一回合用高纪律自动预算协调购买。可能牺牲这一回合装备以预留资金，不赠送现金。

选择即扣次数并写入 `timeoutHistory`；效果保存截止回合。重新打开 UI 或刷新不会再次扣次，也不会重新抽样。存档恢复保留全部记录。

验证：`tests/engine.test.ts` 检查计数与冷却；`scripts/validate-timeouts.mts` 用同种子分支执行三项选择，并验证机制实际变化。某个分支胜率较高只描述该实验，不表示暂停必胜。

暂停规则保存在赛事、系列赛和每张地图，字段为 perMap、durationSeconds、overtimeExtra、cooldownRounds。当前赛历默认 4 次、30 秒、加时不补充、2 回合冷却；引擎也支持其他配置，加时每个 MR3 区块按 overtimeExtra 增加。时长是游戏规则记录，不强制等待真实 30 秒。新图重置次数及短期效果。
