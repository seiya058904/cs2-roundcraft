## 校验结果

- `npm test -- --maxWorkers=2`：20 个文件、162 项通过，含 8 项新增第二批/事实门回归、6 个旧引擎冻结指纹以及同秒事件锚点顺序检查。
- `npm run data:validate`、`npm run build`：通过。
- `npm run sim:commentary`：150 种子、2,875 回合，通过合法事件引用、回放相等、未引用未来事件、随机状态不变、真实语录同回合去重和五回合冷却检查；相应问题计数均为 0。
- `npx tsx scripts/audit-commentary-batch2.mts`：按同一组 32 个 seed/round 比较，识别问题从 7 降至 0。五类为首杀/爆头重复、大狙/首杀重复、道具击杀误套闪光接枪、拆包三次收尾、手雷受害侧别错误。此扫描不覆盖全部语义问题。
- `npx tsx scripts/review-upgrade-commentary.mts`：生成 32 回合、8 类实际已播出场景的审读样本。修正了旧抽样脚本只看“产生节拍”而未确认“实际播出”的偏差。审读仍可见轮转、下包等概括性说明跨回合复现；没有把这些问题写成已解决。
- `npm run test:e2e`：33 项 Chromium 浏览器回归通过，覆盖 390/1024/1280/1440px、回放、同步、出处、存档等。
- `npm run test:offline`、`npm run test:pages`：各 1 项通过，验证本地生产构建的断网恢复与 Worker 模拟、子路径资源。后者是本地测试，没有部署网站。
- 导入幂等检查、包文件哈希、第二批来源字节、首批 364 条字段不变、静态候选 ID 均存在检查：通过。

## 残留问题

- 尚未达到全部原有 36 节拍有真实候选。`even`、`two-v-two`、`rifle-v-awp`、`awp-opening`、`smoke-kill`、`rotation`、`half-time`、`phase` 在此队列中仍无真实候选。
- 高频 `opening` 1、`economy` 1、`trade` 8、`clutch-win` 8，仍低于 10；其余多个池子也低于 3。不能把 R13 开场语录算作 R12 半场结束，不能把完成拆除前的假拆/催拆句用在已拆除之后。
- 124 条静态接线中，111 条在当前队列中具备资格，107 条实际播出；未触发的具名/武器/购买条件需要其他阵容和手工场景进一步覆盖。未启用材料仍可能包含字幕错误、依赖历史比赛或引擎未建模的跳烟、扫射转移、技术暂停等事实，禁止随机投放。
- 原始材料均是用户提供的 AI 字幕整理稿，尚未逐字听录核验；没有扩大真实性认证。
- 目前只完成本轮审读，不能宣称连续两轮所有重复与时间问题清零，也不能宣称全量语义事实已经自动证明。
