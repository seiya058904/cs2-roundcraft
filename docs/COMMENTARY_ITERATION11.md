# 第十一轮阶段结果：候选落选与 BO3 定向验证

日期：2026-10-27。第九、十轮报告保留为历史快照。本轮没有新增暂缓语录接线；反而撤回两条缺少事实依据的旧接线。

## 先核实候选是否真的有依据

第十轮 RW-8-1“一个拆包烟给到位”和 RD-8-8“CT 有一个拆包烟”各有51次候选、0次播出。追查引擎发现：投烟事件只是针对可见敌人所在区域投掷，没有记录为拆包掩护的意图，也没有能证明烟覆盖炸弹的精确几何。同区、CT投烟、包已下不能证明“拆包烟”。因此两条已停止接线，需新增明确用途及覆盖证据后才能恢复；不能把旧候选数当成事实验证。新增反例测试覆盖包已下且CT同区投烟的情况。

这两条属于第九轮之前的接线，不在原345条审读集合中；第十轮所述原345条的剩余242条暂缓数量没有因此改变。当前新包语料中另有这两条重新暂缓。原先对 RD-8-4、RD-8-9、RF-8-5 的拆包进行中事件缺口依然存在；第二时间再空枪的 RD-12-3 仍需可验证的第二阶段和之前空枪关系，不能仅用任意第二次开枪授权。双拉、穿墙、假打响应和缺失枪型也仍需各自证据或机制。本轮没有重新逐句复核所有242项，原逐句理由见 [第九轮清单](COMMENTARY_QUOTE_REVIEW_ITERATION9.md) 与 [第十轮报告](COMMENTARY_ITERATION10.md)。

## 固定 BO3 验证与落选原因

五组真实阵容、100个BO3、239张图、4849回合：Falcons/NAVI、G2/Spirit、FaZe/MOUZ、Vitality/FURIA、Aurora/MongolZ；每组普通AI及合法的T四人中路、CT保守近点配置各用种子301–310，自动禁选。不改选手、事件、随机流或强制选原句。定向决策不计入普通队列覆盖。完整逐项次数、自然播出回合与事件见 [机器记录](commentary-iteration11-validation.json)，复现脚本 `scripts/validate-commentary-iteration11.mts`。

聚焦第十轮之后仍未播的52条已接线新包句，其中5条在本队列首次实际播出：RF-6-14 4次、RD-10-6 5次、RD-9-24 429次、RD-9-29 340次、RD-12-13 1次。后两条计划句的大量播出来自刻意固定的合法站位，不代表普通AI自然频率。

每次候选按对应节拍是否播出、五回合冷却、强度限制和其余候选竞争分开计数；“竞争”是未被前述原因排除但最终选了其他文本的汇总，可能包含渲染的其他限制，不声称单一原因。示例：

## 抽读与事实修正

逐段抽读本队列5条首次播出的各一个完整回合。RF-6-14原句已说灭火，补句又重复“烟灭火/火扑掉”，现改补具名地点；保留精简文本和事件锚点。另发现 Nuke 的外场被 RD-9-6、RD-9-18、RB-10-16 说成中路，同类 RF-4-4 也存在同一风险；这些原句现仅允许实际名为中路的地图节点。正反测试覆盖 Nuke 与 Mirage。其余抽读不能证明全库无近义重复。

自然验证会核对事件锚点、播报重放和随机状态；本轮没有改变模拟胜负规则。检查结果以本轮最终回复为准，构建500 kB提示仍存在。工作区原有及本轮改动均保留，未提交、推送或部署。
