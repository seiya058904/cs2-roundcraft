# 整回合衔接迭代

日期：2026-10-27（Asia/Shanghai）。在阶段解说修复后，继续依据用户提供的风格指南优化“先给情绪，再讲具体原因”、道具与补枪、时间差和收尾节奏。指南中的字幕规模与词频仍为用户材料自述，本轮没有重新核验完整原字幕。

## 修改

本轮未新增或改写真人语录，也未扩写原创语料文件。真实库 1,283 条、原创模板 444 条保持不变；不改人物映射、场景门、阵容、模拟引擎、依赖与远端配置。

`src/domain/commentaryBeats.ts` 的当前文字生成版本为 `causal-story-10`：

1. 首杀、补枪、闪光转化、混烟、爆头、步枪击杀狙击手、对狙等可能描述同一次击杀。现在按真实击杀 ID 合段，选一个主句，其余只补充道具/命中/武器事实，不再各播一次击杀。保留各相关节拍 ID 与事件依据。补枪只把最后一次击杀当作当前动作，前一名队友的死亡仍是独立的先前事件；同秒不同目标的击杀也不合并。
2. 主句仍按该句原有事实门选择真实语录，原文与出处保留；无合适真实语录时才用原创模板或事实句。主句采用原创模板时也保留附加事实，不套真人出处。事件合段不改变实际击杀、时间或参与者。
3. 赛点、常规末轮威胁、换边与加时提示不再受普通高显著事件挤掉；先讲本回合结果和比分，再给阶段提示。提示仍占用原有主要段落预算，并从精简的三个事件名额中预留位置，精简总数继续最多五段。
4. 删去当前引擎首杀后反复出现的长篇通用分析、残局开局的固定拆单挑建议。残局若已选入具体拆包完成段，后续的残局称赞不再重复“最后完成拆包”。仍保留真正的补枪秒差、拆包秒数与比赛结果。
5. 原先无计划引擎继续使用冻结分支与版本，六个旧存档指纹通过。所有新句依实际事件生成，未引入未来事实或比赛随机数消耗。
