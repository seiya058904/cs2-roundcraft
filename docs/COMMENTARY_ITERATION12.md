# 第十二轮：拆包过程、真实换人与自然播出复验

日期：2026-10-27。第九至十一轮报告和逐句清单是历史快照；本报告只覆盖本轮改动和验证，不声称重新逐条审读了所有暂缓项。

## 原句接线与事实边界

原345条集合：第九轮接入101条，第十轮又接入2条；本轮撤回 RD-1-8（单次中路首杀和时间不足以证明“第二时间出”），新增 RF-8-5、RD-8-9、RD-8-4、RD-12-3、RF-12-6，按此集合目前107条接线、238条暂缓。新接线不等于已播出；原文及来源未被改写。第十一轮另撤回的两条拆包烟不属于这个345条集合。本轮也撤回集合外 RF-6-5：保留一颗道具并不证明它是反清用途。

- 计划引擎现记录实际 `defuseStart`、`defuseStop`，分别关联真实下包与开始事件；`defuse` 完成也关联开始。只在炸弹爆炸前开始，依据真实拆包者、工具和时间表达进行中、被击杀、中断及同伴接手；不提前播报未来结局。完成状态、顺序、位置、存活、工具和单一活动拆包均有约束，旧记录不要求补造事件。
- RF-8-5 只在实际开始后；RD-8-9 要求实际拆包者仍在拆，击杀目标是另一个人；RD-8-4 只在拆包者被击杀且炸弹剩余时间大于0、至多1秒时。包点烟仍不能推定为拆包烟。
- RD-12-3 要同一选手的两次AWP明确未命中，期间有同队实际的第二阶段事件，第二次出手距该阶段不超过5秒，且阶段后没有下包；不以事后缺少伤害倒推未命中。RF-12-6 要求同一人本回合第二次AWP击杀，目标确在警家节点。
- 无法证明动作、方向、意图或对应主体的旧句也收紧：例如没有探身/架枪证据时不称静止架枪、贴脸对枪或胸口命中；沙鹰突破A要有本人实际进入A点再击杀；Nuke外场不能叫中路；补枪后捡枪要捡到补枪者亲自击杀对手的掉枪；拆包前击杀须早于实际开始下包。makazze 专属三杀修正名单大小写匹配。
- 双拉、穿墙、跳跃、SSG08、烟雾用途/覆盖几何、骗到回防、被困、具体预瞄及许多跨回合判断仍缺对应机制或可靠上下文；不能仅靠共时、同区、胜负或一次结果填补。原逐条历史原因见 [清单](COMMENTARY_QUOTE_REVIEW_ITERATION9.md)，本轮只覆盖上述明确修正。

## 播报与叙事

残局开始的事实门不变，只在具名选手、恰好一血或特殊大狙装备等严格条件成立时提高优先级，避免普通少打多在几乎每回合被反复播报。首杀、装备差、战术选择、多杀、残局结果、下包、残血、比分转折和最后击杀采用事实驱动的不同口语表达；没有主武器或道具时直说“没有”。回合结束按实际拆包、爆炸、时间耗尽或歼灭解释，不把未击杀的存活说成残局击杀。

新增枪械非致命残血节拍只使用本次真实命中后的血量；燃烧弹致死不再说“0血再不离开”，实际致死时保留伤害和击杀锚点。道具造成的换人单独说“手雷/燃烧弹换人”，不借用“补枪”原句。连续事件同一击杀仍合段并保留 `eventIds`、`sourceBeatIds`；原句后的补述按具体句子去掉同义重复，仍保留人物、人数、时间和出处。此为抽样修正，不证明全库不存在重复。
