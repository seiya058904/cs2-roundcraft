# 高频口语与精选句迭代

日期：2026-10-27（Asia/Shanghai）。当前文字版本 `causal-story-12`。本轮继续按用户精选包优先接线，同时减少普通回合的重复长开头；没有改动真实原文、人物映射、阵容、比赛引擎或依赖。

## 这轮改变

新增 24 条原创短开头（`CX-001` 至 `CX-024`），四个情境各六条：普通回合、近期连分、近期连丢分、双方至少八分且分差不超过一的接近比分。连胜数与队伍取当前地图已结束回合前缀，不能读未来回合。真实语录仍优先，短开头在没有合适且未冷却的真实句时使用。原有 444 条完整记录保持不变，原创总数 468；新句单独标记 `assistant-authored-original-template`、`verifiedSpokenQuote: false`。

两段旧长开头 WJ-008/009 不再作为当前引擎普通回合候选，但原始材料、运行库记录和旧引擎分支均保留。两次手枪局与首次加时的专用开头继续保留。

本轮新增 20 个静态真实语录接线 ID（243 → 263）：

- RF-1-5：实际标准 2-1-2 的普通开局；手枪局不套普通控图/212 开头。
- RD-9-6/18、RF-9-2：实际选择中路控制，或 B 侧分路且计划集合的战术意图；不提前声称已经到达或打赢。
- RW-1-3、RW-6-17、RF-6-8、RB-6-44：按实际购买后装备、阵营与道具分布判断钢枪、无道具、T 道具优势或仅两人持有成套道具，不能只改购买标签。
- RF-12-14、RW-12-3：前者要求当前事件前缀内同一选手至少两次开枪均为爆头且人物符合；后者要求 AWP 首杀与实际静止开枪条件。未启用穿墙、开镜、身位等未建模句。
- RF-2-16/11、RF-2-14、RB-2-8：对应实际二打一补枪、具名火仔补枪、具名 ropz 闪光转化和包点闪光转化；人物/人数/道具条件仍各自取证。
- RF-2-10：必须已经捡枪，且拾取掉枪的击杀 ID 与该选手先前补枪事件的击杀因果相交。解说也保留这次补枪和相关击杀的事件依据；不允许捡到其他尸体的枪就说成这一链条。
- RD-6-8、RW-6-12、RF-6-5/11、RD-9-22：对应两名存活回防队员实际用完道具、CT 回防仍保留大量道具、留唯一道具、到包点后允许交道具，以及已下包后真实回防路线受烟封堵。道具按同秒事件前缀扣除，保枪不冒充回防。

合段后，除了主动作的真实句，也允许从已合并的附加动作选择真实句；每句仍调用自己的原有事实门，不能靠一个宽泛标签绕开条件。只选一个真实主句，保留所有相关节拍和事件依据；不把两种措辞重新播成两次击杀。
