# 地图区域与轮转路线

本文件由 `scripts/document-maps.mts` 从当前实际配置生成。区域名称对应用户指定七图；路线、耗时、枪线与掩体是游戏近似，不是 BSP/导航网格的精确测量。

**行走连通与可见枪线分开定义。** 同区域可交火；跨区域必须有显式枪线。近角架点落位后会放弃跨区域视野。所有路径边双向，移动耗时不得短于边权；火焰阻滞可能增加时间。

Nuke 上下层只通过坡道、秘密通道、通风管等路线连接，不因名称相近就隔层对射。
