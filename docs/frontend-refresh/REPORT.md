# 全站前端与比赛观战界面交付记录

日期：2026-10-26。运行入口：[本地试玩](http://127.0.0.1:5173/)。

## 已实现

比赛页按「比分和地图进程 → 战术指令 → 双方十人 → 解说与复盘 → 详细统计」组织。默认高级设置收起，1280×800 的开局及装备回合首屏可以看到主操作和完整十人面板。向下阅读时显示精简指挥条，和主按钮复用执行入口；同一轮同步连点不会提交两次。

双方采用无头像的镜像观战布局。职业名、当图击杀／死亡、现金、枪械型号与本地 SVG 轮廓、护甲、头盔、重复投掷物数量、拆弹器、炸弹和血量直接对比。阵亡行保持位置，灰化并隐藏不可使用的装备。己方即使在赛事数据中属于客队，也始终在左；换边只切换阵营标签和颜色。390 像素仍为左右两列，装备在单元内换行；额外修复了长名字和 100 血的宽度竞争。

回放提供同一个事件截止位置给状态面板、击杀／死亡、比分和动效。进行中明确标为「购买后现金／开局护甲」，回合结束才显示结算值。历史回合不计入后续击杀、地图比分或系列赛胜者；地图说明也跟随所选回合。快照只读，不修改引擎、随机流或 AI 情报。

Hallmark 检查原始输出保存在截图目录的 `hallmark.json`：13 FAIL、102 REFLEX、4 WARN，不能表述为全绿。处理判断如下：

- 箭头、点分隔文案和历史记录破折号：保留既有游戏操作与紧凑信息表达，不为营销页面文字规则改动这些交互标签。
- BO1／BO3／BO5 和 JSON：为真实赛制及格式缩写，保留正确大小写。
- `thead th` 与窄屏导航均为 sticky top:0：表头属于横向表格容器，不与页面导航共享滚动容器；实际四档截图及表格中心滚动检查未出现重叠。
- 非 4px 倍数的密集间距：按本游戏 HUD 密度和 1280×800 首屏目标保留。正文行宽、继承颜色和标题平衡属于该检查器的其余提醒，页面已用实际截图检查。
- 其自带渲染层因缺少 puppeteer-core 未运行；没有为此新增依赖。实际渲染由项目 Playwright 验证。未把上述保留项伪装成工具通过。

## 性能对照及限制

同一台机器、开发模式 Chromium，使用 CDP Performance 指标，各操作 5 次取中位数，单位 ms。采样脚本和原始 `before.json`／`final.json` 均交付。墙钟包含自动化操作等待，不是 React render 时间或稳定帧率；短样本有机器负载波动。

| 操作 | 墙钟：前 → 后 | 主线程 Task：前 → 后 | Script：前 → 后 | Layout：前 → 后 | Style：前 → 后 |
|---|---:|---:|---:|---:|---:|
| 选手筛选 | 58.24 → 51.16 | 31.96 → 28.57 | 7.45 → 6.74 | 0.77 → 0.67 | 6.02 → 0.85 |
| 页面切换 | 294.69 → 282.60 | 110.40 → 54.54 | 7.80 → 8.44 | 3.31 → 2.21 | 23.25 → 4.80 |
| 继续一段回放 | 67.15 → 84.88 | 19.90 → 22.01 | 10.39 → 11.57 | 1.50 → 1.59 | 0.92 → 1.51 |

筛选和切页的主线程及样式开销下降；回放本次样本增加约 2.11ms 主线程开销，没有取得全面性能改善。未据此声称 60fps 或生产环境指标。最后补齐拾枪／炸弹携带的装备动效触发后未重复这组性能采样，相关交互回归已通过。

剩余限制：主入口压缩前产物约 508.40kB（gzip 177.57kB），仍触发 Vite 500kB 分块提醒；本轮未为消除提醒进行无关拆包或依赖调整。触屏为 Chromium 模拟，未实测实体手机、Safari 或不同刷新率硬件。现有应用使用原生确认框和文件选择器，本轮没有新增自定义弹窗，系统窗口的滚动不由网页控制。护甲不伪装为逐事件实时数据，仍明确采用开局／结算口径。
