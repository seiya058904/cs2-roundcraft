# 阶段解说节奏迭代

日期：2026-10-27（Asia/Shanghai）。承接新三包接入，本轮集中处理现场解说照念内部状态、动作重复启动、等待后的状态被去重吞掉，以及真实语录之后的生硬事实接续。长期自然度目标仍在迭代。

## 修改与来源

- 用户五批语录仍为 1,283 条，原文、编号、出处、人物映射与事实场景门不变。新三包仍优先于原创素材，不为扩大覆盖放宽条件。
- 新增 84 条原创阶段表达，14 个规则/状态家庭各 6 条。原有 360 条完整记录保持不变，原创总数为 444。新句明确标记 `assistant-authored-original-template`、`verifiedSpokenQuote: false`，不混进真实语录计数。
- `commentaryBeats.ts` 按结构化状态选择阶段句，保留不同状态的先后变化，合并同队同秒的集结结束与推进启动；回合结束的指令清理不当成新动作。普通回合最多两段阶段解说，高光最多三段，留出交火与关键结果的位置。
- 真实语录接原创阶段事实时，主句仍保存原语录 `templateId`、`quoteSource`，辅助句另记 `supportTemplateId`。两者都计入同回合去重与五回合冷却。详细、精简、回放均可确定性重建；不修改比赛随机流。
- 当前解说版本 `causal-story-9`；不含计划的旧引擎仍使用原分支与版本，六个冻结存档指纹通过。

## 仍需迭代

自然样本仍能看到一次击杀被首杀、混烟或闪光转化从不同角度连续说到；残局开局的通用解释也偏固定。部分赛点/换边/加时段排在同秒收尾前，句间节奏还可以更顺。下一轮先处理这些整回合衔接，再补首杀、经济等薄池，不通过重播同一动作或挂错人物来提高语录数量。

尚未证明所有局面都像真人、全部重复已消除或每个池子都充足。`even`、`smoke-kill` 的真实候选在普通队列仍未自然触发，专门正反夹具不计入自然覆盖。当前仍是文字现场解说，没有语音或声音克隆。

所有改动仅保留在本地，未提交、推送、合并、部署或更新依赖。
