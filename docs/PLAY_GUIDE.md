# 开始游玩

## 先体验一场比赛

1. 打开 http://127.0.0.1:5173，点击“快速开赛 · Vitality vs FURIA”。默认直接完成禁选进入 BO3。
2. 在“战术指令”选一个指挥档位：**托管**（教练 AI 每回合自选战术与购买）、**稳健**、**均衡**（默认）、**激进**（经济都自动），或 **手动**——展开原有的单个战术预设、六档经济、战术池、阶段调整、指挥偏好和五人站位。档位会记在本机浏览器里。
3. 点击“执行下一回合”，现场解说逐段显示，最新一句固定在解说席底部大字显示，之前的解说在上方滚动。打开 **连播** 后，本回合播完会按当前档位自动开下一回合；需要你选边、回看历史回合、播报暂停、叫教练暂停或比赛结束时自动停下。连播默认关闭。想自己控制阅读节奏，把播报速度改为“手动逐段”，再点击“继续下一段”。
4. 每段下方的“依据”可展开事实依据和已调用语录出处；“场外分析”给出本图走势、攻防对比（首杀、下包转化、回防、残局、多杀、以弱胜强、手枪局）、本图最佳、手感与宿敌，以及系列技术统计和地图路线；“战术复盘”“精确账本”可主动查看完整结算。分析只读取你已经看完的回合，回放时不会剧透。比分下方的存活条和炸弹标签同样只跟随已播出的事件。解说绰号不改变名单和统计中的正式名字。
5. “教练暂停”显示三种建议，每次只选一种并消耗次数；“自动 3 回合”“模拟整图”“模拟 BO3”适合快速推进。后台模拟可以停止，保留安全边界进度。
6. 桌面窗口不小于 1240×760 时，比赛页是一屏“转播台”：比分、指挥条、双方阵容、解说席、胜率与击杀信息都在视口内，页面本身不需要滚动，只有解说、分析和击杀列表在各自面板内滚动。更窄或更矮的窗口保持原来的纵向页面。
7. 完成比赛后返回沙盒配置；若想亲自禁选、改变赛制或创建五人阵容，从“沙盒”开始。

## 接管俱乐部

从“总览”选择队伍并开启职业生涯。“我的战队”查看角色、能力和地图准备；“赛事中心”选择获邀赛事并进入本队对局。未获 Major 邀请时，可以参加公开赛提升模拟排名。比赛结束后点击“结算并返回赛事”，再进入下一场或后台完成赛事。

赛事间可以在“转会窗口”交换选手；赛事进行中名单锁定。赛季结束后进入下一季，已保存的旧季统计会归档。“独立沙盒”保留最近一场沙盒比赛，不覆盖生涯比赛；正在进行的生涯对局需要先结算，再恢复沙盒。

## 保存与恢复

在当前网页会话中，切到选手数据库、存档等页面再返回比赛，会保留手动指令、回放回合和解说位置；返回时暂停播报，连播保持关闭。调整播报速度不会从第一段重播。“直接显示”仍会展开全部解说。新建比赛、载入或导入存档会清除旧草稿；刷新网页不保留这些临时阅读与指挥设置。换图、换边仍会清除不适用的站位和阶段调整。

自动存档和三个手动槽位都保存在当前浏览器、当前地址端口。5173 开发版与 4173 预览版的存档互不共享，需要用“导出 JSON / 导入 JSON”转移。导入会先校验，不合格文件不会覆盖当前进度。

顶部显示“正在保存 / 已保存 / 保存失败”。只有本地事务提交成功才显示已保存；失败后可点击“重试保存”，或在存档页导出当前进度。后续操作会再次尝试自动保存。

手动槽位显示保存时间、战队、赛季和比赛进度。载入、导入以及覆盖已有手动槽位时，会在同一事务中保留替换前的内容；备份失败则不替换。“恢复替换前进度”可以恢复最近一次替换，恢复时也会备份当前进度。替换备份只保留一份，与校验失败原文的恢复备份分开；长期留存仍应导出 JSON。

逐段播报期间，指挥区暂不显示后续结算的现金和暂停建议；场外分析仅统计已揭示的完整回合。选择“战术复盘 / 精确账本”会主动揭示本回合全部结果。执行下一回合仍可跳过当前播报。

自动恢复失败时，应用保留原始数据，存档页可导出恢复备份；开始新进度时先把原文备份，再保存新状态。建议在跨版本更新前主动导出 JSON。此机制不代替浏览器外的文件备份。

## 启动与离线

开发服务关闭后，在项目目录执行 `npm run dev`，重新打开终端显示的地址。

生产离线版先执行 `npm run build`，再执行 `npm run preview -- --port 4173`。打开 http://127.0.0.1:4173，首次完整加载并缓存后，可断网刷新和继续比赛。首次安装依赖和首次缓存需要网络/可用本地服务；开发版不安装离线缓存。

战术和胜负均来自模拟估值。当前明显偏 T、地图为区域抽象；具体已实现范围与未完成项见 QA_REPORT.md 和 TARGET_STATUS.md。

最新称呼规则：解说选手绰号后附职业名，例如“载物（ZywOo）”；名单和统计的正式名字不变。
