# 开始游玩

## 先体验一场比赛

1. 打开 http://127.0.0.1:5173，点击“快速开赛 · Vitality vs FURIA”。默认直接完成禁选进入 BO3。
2. 在“战术指令”选择战术、经济和风险；展开“五人初始站位与路线”可逐人指定区域和架点方式。
3. 点击“执行下一回合”，现场解说逐段显示。想自己控制阅读节奏，把播报速度改为“手动逐段”，再点击“继续下一段”。
4. 每段下方可展开事实依据和已调用语录出处；“战术复盘”“精确账本”可主动查看完整结算。解说绰号不改变名单和统计中的正式名字。
5. “教练暂停”显示三种建议，每次只选一种并消耗次数；“自动 3 回合”“模拟整图”“模拟 BO3”适合快速推进。后台模拟可以停止，保留安全边界进度。
6. 完成比赛后返回沙盒配置；若想亲自禁选、改变赛制或创建五人阵容，从“沙盒”开始。

## 接管俱乐部

从“总览”选择队伍并开启职业生涯。“我的战队”查看角色、能力和地图准备；“赛事中心”选择获邀赛事并进入本队对局。未获 Major 邀请时，可以参加公开赛提升模拟排名。比赛结束后点击“结算并返回赛事”，再进入下一场或后台完成赛事。

赛事间可以在“转会窗口”交换选手；赛事进行中名单锁定。赛季结束后进入下一季，已保存的旧季统计会归档。“独立沙盒”保留最近一场沙盒比赛，不覆盖生涯比赛；正在进行的生涯对局需要先结算，再恢复沙盒。

## 保存与恢复

自动存档和三个手动槽位都保存在当前浏览器、当前地址端口。5173 开发版与 4173 预览版的存档互不共享，需要用“导出 JSON / 导入 JSON”转移。导入会先校验，不合格文件不会覆盖当前进度。

自动恢复失败时，应用保留原始数据，存档页可导出恢复备份；开始新进度时先把原文备份，再保存新状态。建议在跨版本更新前主动导出 JSON。此机制不代替浏览器外的文件备份。

## 启动与离线

开发服务关闭后，在项目目录执行 `npm run dev`，重新打开终端显示的地址。

生产离线版先执行 `npm run build`，再执行 `npm run preview -- --port 4173`。打开 http://127.0.0.1:4173，首次完整加载并缓存后，可断网刷新和继续比赛。首次安装依赖和首次缓存需要网络/可用本地服务；开发版不安装离线缓存。

战术和胜负均来自模拟估值。当前明显偏 T、地图为区域抽象；具体已实现范围与未完成项见 QA_REPORT.md 和 TARGET_STATUS.md。

最新称呼规则：解说选手绰号后附职业名，例如“载物（ZywOo）”；名单和统计的正式名字不变。
