# 决胜阶段与败方残局迭代

日期：2026-10-27（Asia/Shanghai）。当前文字生成版本 `causal-story-11`，承接整回合衔接修复，继续补齐加时与收图语义。原有语料文件与清单未改，真实库仍为 1,283 条、原创模板 444 条；未改比赛引擎、身份、依赖或远端。

## 行为改变

- 加时赛点使用模拟器现有 `mapWinner` 判断下一分能否结束本图，避免把 15:15、18:18 错报为只差一分。补充加时前半场换边、第二/第三轮加时提示；开局给出当前加时轮次与回合。赛点压力只取本回合开始比分，不能倒灌刚发生的结果。
- 区分地图结束和系列赛结束。系列赛判断只统计当前地图之前的胜图，不读后面地图结果；BO3/BO5 不能在第一张图结束就说整个比赛结束。结束与阶段提示都在当前回合结果/比分之后，详细和精简均保留，原有段数预算与五段精简上限继续执行。
- 守住赛点有独立点评，并抑制同回合收尾再次抽中同类赛点反转句。
- 败方残局只在残局开始后实际完成击杀、且没有保枪存活时提供点评，说明“打掉几个但没赢”；不在普通一打五失败或保枪后补一段通用失败感叹。语录的“尽力了”仍有事实门。
- “最后暂停”只读取当时规则额度与截至该回合的暂停记录。后面回合的暂停不能让历史回放提前说次数已用完。
- 修正审读发现的开局压力句重复：真实语录、原创模板、事实回退三条路径都只给一次当前阶段提示。

新增静态接线 12 条：RD-3-11/12、RW-3-5、RB-3-2 用于有实际反击的败方残局；RB-7-14/20、RF-7-3 仅用于系列赛已结束；RB-7-10 用于真实加时赛点；RB-7-2、RD-7-1 用于守住赛点（后者还要求猎鹰仍握有赛点）；RD-11-6、RB-11-39 要求本次暂停后额度为零。另复用已接线的泛用赛点/加时语录。12 条均在本轮两组普通验证队列并集中实际播出，不拿静态接线代替自然使用。
