# 比赛引擎规则

## 状态与确定性

`Series` 保存种子、PRNG 状态、双方阵容副本、禁选、地图顺序及已完成回合。`resolveRound` 是逐回合和批量模拟的共同入口；渲染、播报速度、墙钟时间均不参与比赛随机数。解说使用独立字符串哈希选句。

一个回合按以下顺序执行：验证指令 → 换边/重置 → 购买与队友发枪 → 分配合法路线 → 一秒步长移动/信息/道具/交火 → 下包与拆包计时 → 判断终局 → 现金和团队状态结算 → 统计、语义节拍与解说。

当前时间步长为一秒，因此 3.2 秒下包在整数时钟上向上落到 4 秒。移动路线至少消耗配置中的边权时间，没有瞬移。处于移动边上的选手暂不参加枪线交火，这是明确的区域级近似。

## 胜负与系列赛

- 常规每半场 12 回合，先到 13 分获胜；12:12 进入加时。
- 加时 MR3，15:15 则继续下一轮 MR3；每个加时半场换边并重置经济。
- 下包前可通过消灭全队结束回合；下包后 T 即使全部阵亡也必须等待拆包或爆炸结算。
- 无包且时间达到 115 秒由 CT 获胜；下包后 40 秒爆炸；有钳 5 秒、无钳 10 秒拆除，须在爆炸前完成。
- BO1/3/5 对应 1/2/3 张地图获胜。选图不重复，地图结束后不能继续加分。

## 十二项个人能力的作用点

| 能力 | 实际作用 |
| --- | --- |
| aim | 枪械命中与爆头抽样 |
| entry | 首杀出现前 T 侧破点交锋 |
| awp | AWP 命中贡献 |
| defense | CT 防守交锋贡献 |
| utility | 闪白概率/时长、HE 与火焰伤害 |
| gameSense | IGL 根据已见多人防守调整方向；理性保枪 |
| positioning | 枪线对决贡献，与实际掩体和位置共同计算 |
| teamwork | 多名队友可见同一目标时的协作贡献 |
| clutch | 本队仅一人生存时的对决表现 |
| consistency | 回合状态波动幅度 |
| composure | 比分进入关键分后的状态波动 |
| peakPotential | 小概率回合爆发幅度 |

没有直接用某个总能力值决定整图赢家。`tests/causality.test.ts` 对每项能力做独立扰动并检查事件发生变化；该检查证明参与，并不证明所有参数已达到最终竞技平衡。

## 八项团队维度

默契影响进攻队形到位时间差；执行力与地图战术熟练度共同控制集结间隔；沟通和地图准备影响从真实情报到支援的延迟；临场调整影响对连续战术的反制；经济纪律影响低预算预留；信念缓慢反馈并限制在范围内。熟练度按 `地图:战术` 保存，阵容变化降低熟练与默契，比赛逐步恢复。

## 信息、战术与位置

22 个战术由攻守侧、目标、启动时间、是否分路、是否佯攻及侵略性区分。CT 的轮转读取实际接触区域，不读取 T 的秘密目标。T 的临场转点依据当前看见的守点人数。阵亡 IGL 不会继续发出临场行动指令。

近角架点在落位后放弃相邻区域视野，让敌人进到本区域再发生近距离交火；常规架点保留地图枪线。收缩、前顶、分路和快慢节奏会改变到点人数、武器有效距离和可补枪时间。

## 伤害与事件

伤害受武器、距离、护甲/头盔、站位、闪白、烟雾和状态共同影响。HP、死亡、补枪、道具和装备变化均进入有 ID 的事件账本。燃烧弹可在投掷者死亡后持续生效，该伤害仍引用生前投掷事件；这是允许的延迟伤害，不是死者继续开枪。

尚未模拟：完整命中盒、墙体穿透材质、弹匣/换弹、投掷物弧线、友伤、精确爆炸范围、炸弹爆炸对幸存者的伤害。当前爆炸只结算回合胜负，存活者携带装备进入下一回合；不能将本引擎当成真实 CS2 服务器。

## 扩展校验与回放

事件校验进一步核对：投掷库存扣减、枪械持有、到位与行程因果、跨区域枪线、掉落来源与唯一拾取、唯一末尾 roundEnd。现场回放从回合初态和已播报事件前缀重建 HP/存活/位置，不读取后续伤亡。统计仍以已完成的完整事件计算。
