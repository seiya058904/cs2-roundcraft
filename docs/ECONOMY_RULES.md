## 购买

支持 auto / eco / halfBuy / forceBuy / fullBuy / awpPriority。ECO 不购买；halfBuy 最多花 $2,000 且预留 $2,000；auto 在资金偏低且纪律较好时预留后续预算。手枪局 auto 使用合法 $800 预算。

护甲 $650；已有护甲时补头盔 $350；CT 拆弹器 $400；烟 $300、闪 $200、HE $300、T 燃烧瓶 $400、CT 燃烧弹 $500。最多四枚道具，当前自动策略每种最多购买一枚；验证允许最多两枚闪光。

已实现枪械：Glock、USP-S、P250、Five-SeveN、Tec-9、Deagle、MP9、MAC-10、FAMAS、Galil、M4A1-S、AK-47、AWP。实际价格在 `src/domain/economy.ts`，每笔购买检查资金与阵营合法性。

已有长枪不会重复购买。持枪队友可以用自己的剩余现金为手枪队友购买本侧合法长枪，发枪者实际扣款、接收者不扣款，`donation` 事件记录双方、枪械与价格。ECO/halfBuy 不自动出资发枪，auto 保留 $1,000。这不是把现金直接转账给队友。

## 携带与捡枪

存活者保留当前武器、护甲、头盔、拆弹器及剩余道具；死者下一回合恢复默认手枪。死亡枪械在实际死亡区域形成一次性可捡取掉落；到达同区域、且新枪价值更高时才捡取。允许合法捡到敌方阵营枪械。

每名选手账本记录购买前资金、支出、购买后资金、初始装备、击杀奖励、目标奖励、团队奖励、终局资金及携带装备。检查式为：

`终局现金 = min(16000, 购买后现金 + 击杀奖励 + 目标奖励 + 团队奖励)`。

未实现完整的地面武器交换、道具捡取、装备退款、每种现实枪械与淘汰赛组织者独有配置。当前所有赛事使用同一经济规则包。
