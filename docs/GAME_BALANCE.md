# 游戏平衡与实验解释

全部能力、地图参数和比赛概率为模拟估值。选手能力现参考 HLTV 年度排名、有限统计与职责奖项换算；比赛机制参数未做真实比赛拟合，因此不能把模拟胜率当成职业赛事预测。

## 校准方法

`sim:stress` 在七图、两种起始侧、不同强弱配对间轮换，逐回合验证经济/HP/因果/地图移动/胜负/统计等不变量。完整失败对象连同 seed 会写入 `docs/stress-failure.json`，便于重现。

`sim:calibrate` 固定 Vitality / FURIA，沿真实 AI 禁选路径运行；它会集中在 AI 偏好的地图，不能替代全图平衡测试。

`sim:tactics` 采用等能力 75、Dust II、第二回合受控预算、500 个配对种子。改变一组策略或架点方式，再比较 CT 胜率、击杀、下包、结束时间、补枪及道具伤害。该受控实验不代表自然生涯环境。

## 已发现并修正的问题

- 初始 CT 支援使用过早的单次接触且队形易被整齐突破，造成明显 T 偏置；现已按当前可见接触更新、保留异侧锚点、加入窄入口与移动枪法影响。
- 行走连通不等于枪线可见，特别是 Nuke 上下层。已分离路线与显式视线。
- 原“近点埋伏”把守方送到前压路线。现改为包点掩体近角，舍弃跨区域视野以换取真正的近距离接敌。
- 默契不再仅叠加统一命中贡献，参与队形到位间隔；个人协作在实际共同可见目标时生效。
- 烟雾可灭火；火焰持续伤害、合法队友发枪都进入经济与事件校验。

## 尚需持续校准

最终万图样本共 205,677 回合，各图 CT 回合胜率为 37.11%–41.95%，仍明显偏 T。详见带源码指纹的 `stress-report.json`；机制修复已验证，但不能宣称平衡完成。

当前参数仍有模型局限：区域分辨率较粗、移动途中暂不交火、未模拟弹药、每侧 AI 策略选择粗粒度、炸弹不造成终局伤害、全武器库未覆盖。不能通过直接强制某队获胜、暗改随机种子或给“暂停成功”统一胜率奖励来掩盖问题。

## 统计口径

ADR = 对敌实际有效 HP 伤害 / 回合数；过量伤害不计。KAST = 当回合击杀、达到伤害助攻门槛/闪光助攻、存活或被及时补枪之一的回合占比。闪光助攻另列，伤害助攻门槛为 40 HP。补枪窗口为 5 秒并要求地图路线足够近。

CTM Rating = `0.35 × K/R + 0.25 × (1 − D/R) + 0.25 × ADR/80 + 0.15 × KAST/100`。它是项目自定义指标，不冒充 HLTV Rating。MVP 按赛事内该指标选择，属于游戏近似。

## 后续对照发现

等能力、镜像角色对照曾发现 Dust II / Mirage 部分分布完全一致；根因是共享主干路线与耗时。现七图分别配置连接、耗时及包点距离/掩体估值，地图说明表从实际配置生成。路线估值不宣称为实测 CS2 跑图。

默契参与双方附近队友阵亡后的补枪反应时延（0–4 秒，受个人协作共同约束），不直接抬高命中率。较高默契并不保证每个特定路线组合都更强；站位、提前暴露和道具仍可改变结果。

`sim:matrix` 报告能力、纯 ECO、完整购买与默契对照，不用一次实验宣称现实胜率。JSON 报告记录模拟源码 SHA-256、生成时间和机器配置，便于区分修复前后版本。

赛季汇总按累计回合重新计算 ADR、KAST 和 CTM，不平均各场百分比。闪光助攻计入 A，同一个助攻者对同一击杀只计一次 A。新赛季归档旧季统计；旧存档不存在的历史数据不补造。

## 当前系数与边界

以下是游戏估值的实际作用点，不是现实职业能力的测量结论。概率先相加局部贡献，再乘遮蔽因素，最后限制在 0.035–0.94；它只决定一次实际交火，不决定回合赢家。

| 项目 | 作用与范围 | 有效条件 / 期限 |
| --- | --- | --- |
| 枪法 | `(aim−70)/160`；爆头概率 `0.1+aim/650` | 当前枪械交火 |
| 狙击 | `(awp−70)/200` | 当前持有 AWP |
| 站位 | `(positioning−70)/500` | 当前枪械交火；与区域掩体分别计算 |
| 突破 / 防守 | 突破 `(entry−70)/350`，防守 `(defense−70)/450` | 前者仅首杀之前的 T；后者仅 CT，互斥 |
| 个人地图熟练 | `(proficiency−70)/600` | 当前地图交火 |
| 团队协作 | `min(0.08,(共同可见队友数−1)×teamwork/2000)` | 队友必须存活、到位、具有合法枪线 |
| 残局 | `(clutch−70)/350` | 只在本队仅剩一人时 |
| 信念 | `(belief−70)/1500`；局间反馈范围 48–86 | 回合结算后更新；新半场不赠送永久枪法 |
| 稳定 / 抗压 | 稳定性决定回合波动；关键分时乘 `(110−composure)/70` | 每回合抽样一次 |
| 爆发潜质 | 每回合 1.5% 概率附加 `peakPotential/600` | 仅该回合；仍受命中上限约束 |
| 闪白 / 烟雾 | 命中乘 0.22 / 0.48 | 各自有效期；可以同时存在 |
| 区域掩体 | 已落位防守/下包后站稳者扣 `cover×0.35`，其他扣 `cover×0.04` | 掩体受实际目标区域限制 |
| 移动后开枪 | 到位不足两秒扣 0.12 | 架住后不再扣减 |
| 执行与默契 | 到位随机间隔上界 `(300−execution−familiarity−chemistry)/24` 秒 | 进攻布置阶段，不是命中加成 |
| 补枪反应 | `round((100−chemistry)/35+(100−teamwork)/70)`，0–4 秒 | 附近可见交锋发生队友死亡后，双方均适用 |
| 沟通与地图准备 | CT 支援延迟 `max(1,16−communication/10−preparation/20)`；快速轮转再减两秒，实际不早于收到情报 | 需授权临场调整，且有接触情报 |
| 临场调整 | `adaptability/140` 的反制选择机会 | 最近五回合出现至少三次同向进攻 |
| 道具熟练 | 投掷机会 `0.1+familiarity/800` | 有库存、可见对手、未选择保枪 |

暂停效果互斥：每队当前只有一个短期效果槽。位置建议影响下一回合路线分配；稳住节奏把状态波动乘 0.45，持续两回合；经济建议下一回合以 100 纪律选择自动预算。新建议不能叠加多层命中奖励，新图清空短期效果。

`utility` 决定闪白概率 `utility/110`、时长 `2+utility/40` 秒，HE 名义伤害 `10+0.3×utility`，火焰每秒 `8+utility/20`；最终伤害取整并限制在目标剩余 HP。火持续七秒且可被烟扑灭，投掷者死亡后可持续，回合结束则停止。

本轮选手数据更新后重跑了万图压力、生涯和解说验证。matrix、tactics、calibration、timeout 报告保留历史源码指纹，未在当前选手数据下重跑；不能将其历史结果作为当前参数的验收。
